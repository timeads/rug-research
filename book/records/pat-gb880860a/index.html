Research notes

This is a British priority document for a Singer-Cobble needle-plate patent (US3398708A, "Needle plate for tufting machine"). It suggests that machine development was happening at the Blackburn plant, not just in Chattanooga. Verified Oct 2026 by web search only. patents.google.com and Espacenet could not be opened from the sandbox, so I did not read the document itself.
