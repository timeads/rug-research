Research notes

Paper 《基于PMAC的簇绒机零编程数控系统研究》 ('Research on a zero-programming CNC system for tufting machines based on PMAC'). It uses a PC+NC structure built round a PMAC multi-axis motion controller. Patterns are drawn in AutoCAD, a customised CAD/CAM layer extracts contour points and generates NC code automatically, and Visual C++ software talks to the PMAC through the PComm32 library to tuft complex rug designs. It shows Chinese universities building CNC control for tufting between the first robot-gun patents and the 2014 Shenyang/Yiwu patent (pat-cn104562491a). Only a metadata page on the Sciencepaper Online (paper.edu.cn) platform was seen; the full text was not read. Whether the machine is a single gun head or a broadloom machine is not stated.
