Research notes

Customs code HS 84479011 (簇绒地毯织机). March 2025 alone: Jiangsu imported one machine at US$665,441; Zhejiang one at US$471,660. Citation check (Oct 2026, from search results; pages not opened): confirmed in a different source. Figures match: Jiangsu, general trade, 1 unit, US$665,441, and Zhejiang, general trade, 1 unit, US$471,660. The page has 28 records for the month and only the first rows were visible, so 'alone' and per-province totals are unverified. Context: in Feb 2025 Jiangsu imported 40 units for only US$736,158, so many imports under this code are low-value. 'High-end' is an inference from the unit price. Source: 2025年03月份簇绒地毯织机进口数据统计(84479011) (March 2025 import statistics for tufted-carpet looms, HS 84479011), 报告大厅 chinabgao, March 2025.
