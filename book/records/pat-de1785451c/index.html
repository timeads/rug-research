Research notes

This is a German tufting machine from Girmes, the Oedt/Krefeld plush maker. It is the nearest thing to a Krefeld tufting-machine patent found. No patent naming Zangs turned up. It partly qualifies the existing finding that "Germany tufted early but never built the machines" (ner-de-no-machines), because German pile-fabric firms did patent tufting machinery even if they did not build it commercially. Verified Oct 2026 by web search only. patents.google.com and Espacenet could not be opened from the sandbox, so I did not read the document itself.
